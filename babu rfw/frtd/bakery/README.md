# Bakey route

The bakery page is integrated into the main storefront at `../pubivc/index.html#/bakery`. This folder's `index.html` forwards there for compatibility. The canonical implementation lives in `../pubivc/src/components/bakery-page.js`, `../pubivc/src/data/bakery-products.js`, and `../pubivc/src/styles/bakery.css`.
